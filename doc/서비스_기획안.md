# 강화도 관계인구 강화 프로젝트

> **"환대로 만들어가는 세계"**
> 청풍 잠시섬의 모든 프로그램을 하나로 잇는 **강화도 통합 플랫폼** — 일회성 방문객을 넘어, 강화의 변화를 함께 만드는 관계인구를 위한 서비스

- **팀**: 전현승 · 김민경 · 이용찬 · 정채연 (청풍 × 단풍)
- **배포**: [https://ganghwa-universe.vercel.app/](https://ganghwa-universe.vercel.app/) *(디자인 보완 중)*

---

## 1. 배경 및 문제의식

### 큰 틀 — 지역소멸
- 한국 지방소멸 위기 = 인구 감소 + **관계 단절** + 지역 서사 소멸
- 기존 대응(관광객 유치·경제 활성화)은 일회성 소비에 그침 → 지역과 사람 사이의 **관계**를 만들지 못함

### 작은 틀 — 관계인구
- **관계인구**: 지역에 살지 않아도, 애정과 연고감을 갖고 지속적으로 관여하는 사람
- 생활인구(양적 체류)와 달리 **소속감과 관계의 질**에 초점
- 2010년대 중후반 일본에서 대두된 개념

### 우리가 만들려는 것 — 관계의 장(場)을 온라인으로
- 잠시섬은 라이프·네트워크·창작·테크 4개 카테고리의 다양한 프로그램을 운영하나, 이를 잇는 디지털 공간 부재
- 관계인구가 되지 못하는 이유 = 의지 부재가 아닌 **통로 부재**
- 목표: 오프라인에서 싹튼 관계를 온라인에서 지속하는 **디지털 환대 공간** 구축

---

## 2. 프로젝트 개요

- **주체**: 협동조합 청풍 × 단풍
- **통합 대상**: 청풍 잠시섬 전체 프로그램 (텃밭, 요가, 차 만들기, 교류 모임 등) + 운영 관리 대시보드
- **핵심 문제**: 각각의 프로그램 경험이 참여자 개인의 기억에만 머물고 이어지지 못함
- **솔루션**: 잠시섬 전체 프로그램을 통합하는 **강화도 통합 플랫폼** 설계·개발
- **목표**: 참여자·사장님·크루 3역할이 하나의 플랫폼 안에서 연결 → 방문 이후에도 지속되는 관계인구 형성

## 3. 문제 정의

> "강화에서의 경험은 즐거웠어요. 텃밭을 가꾸고, 차를 함께 만들고, 취향이 맞는 사람들을 만날 수 있었어요. 그런데 여행이 끝나면 강화에서 텃밭이 어디까지 확장되는지, 내가 다녀온 곳에 무슨 일이 일어나는지 알 수 있는 통로가 없었어요. 관계가 거기서 멈춘거예요."
> — 유저 인터뷰 中

| # | 문제 | 현상 |
| --- | --- | --- |
| 01 | **일회성 구조** | 여행이 '신청 → 참가 → 종료'로 끝남. 참여 이후 연결 고리 없음 |
| 02 | **진행상황 불투명** | 프로그램 진행 상황을 외부에서 파악할 방법 없음 |
| 03 | **재연결 통로 부재** | 경험 후 관심은 남지만, 다시 강화에 닿을 수 있는 채널 없음 |

## 4. 접근 방식

> 체류는 카드로, 카드는 도감으로, 도감은 임팩트 있게

3가지 문제에 3가지 방식으로 응답한다.

| 문제 | 해법 | 구현 |
| --- | --- | --- |
| 일회성 구조 | 경험을 기록으로 남긴다 | 카드 작성 → 도감 아카이브 |
| 진행상황 불투명 | 강화의 성장을 공개한다 | 임팩트 대시보드 (누구나 접근) |
| 재연결 통로 부재 | 강화가 먼저 손을 내민다 | 사장님 편지 + 크루 하이파이브 |

### 도감 (Collection)
- 참여자가 강화에서 남긴 카드의 개인 아카이브
- 카드 앞면: 사진 + 메모 / 뒷면: 사장님 편지 답신
- 크루 하이파이브 도착 시 알림

### 임팩트 (Impact)
- 강화 전체 프로그램 진척을 보여주는 **공개 대시보드** (로그인 불필요)
- 포인트·랭킹·경쟁 기능 의도적 제거 → 부담 없는 접근 유도

### 관리자 콘솔 (Admin)
- 크루가 모든 프로그램을 직접 등록·관리하는 운영 허브
- 에피소드 진척 마킹 시 임팩트 대시보드에 실시간 반영

## 6. 유저 플로우

### 01 참여자 — "내 흔적이 쌓인다" (STACK)

```
/entry (QR 스캔)
  → 카카오 로그인
  → 사진 + 메모로 카드 작성
  → /collection 도감에 즉시 저장
  → /impact (강화가 자라는 모습 확인)
```

### 02 크루 — "환대로 응답한다" (RESPOND)

```
/crew에서 오늘 들어온 카드 확인
  → status를 공개/비공개로 토글
  → 하이파이브로 가벼운 응답
  → /admin에서 에피소드 계획 / 과정 / 완성 마킹 → 임팩트 자동 반영
```

### 03 사장님 — "관계가 다시 살아난다" (LETTER)

```
/owner에서 우리 가게 카드 확인
  → Gemini 초안을 바탕으로 편지 작성·다듬기
  → 참여자의 도감 카드 뒷면에 답신 도착
```

## 7. 핵심 기능 명세

### 7-1. 카드
- 강화에서의 순간을 기록하는 **최소 단위**, 서비스 전체 데이터의 씨앗

| 필드 | 내용 | 제약 |
| --- | --- | --- |
| 사진 | 현장 촬영 이미지 | 최대 1장 |
| 메모 | 그 순간의 감상 | 짧은 메모 |
| 날짜 | 카드 생성 일시 | 자동 입력 |
| 장소 | 방문한 가게 또는 장소 | QR 연동 |
| 참여 에피소드 | 연결된 프로그램 에피소드 | 자동 연결 |

카드 1장의 효과:
- 도감에 저장 → 떠난 뒤에도 강화에 닿을 수 있음
- 사장님 편지 트리거 → 관계 재개
- 크루 하이파이브 트리거 → 회차 활성화
- 임팩트 노드맵 + 누적 집계에 기여

### 7-2. 도감 (`/collection`)
- 참여자가 강화에서 쌓은 카드 아카이브
- 카드 앞면: 사진 + 메모 / 뒷면: 사장님 편지

### 7-3. 임팩트 대시보드 (`/impact`)
- 로그인 무관, 누구나 접근 가능한 공개 페이지

| 섹션 | 내용 |
| --- | --- |
| Section 01 — 관계의 지도 (노드맵) | 카테고리·프로젝트·가게·참여자를 노드로 연결한 라이브 그래프. 마우스 오버 시 공개 카드 미리보기 |
| Section 02 — 카테고리별 현황 | 라이프 / 네트워크 / 창작 / 테크 에피소드 완료 비율로 진척도 표시 |
| Section 03 — 최근 카드 | 오늘 강화도에서 일어난 순간 피드 |

### 7-4. 관리자 콘솔 (`/admin`)
- 카테고리 / 프로젝트 / 에피소드 등록·수정·삭제
- 가게 추가 및 사장님 코드 발급

## 9. 기술 스택 및 아키텍처

**Core Stack**: Next.js (App Router) / Supabase / PostgreSQL / Gemini API / Vercel

| 영역 | 구현 방식 |
| --- | --- |
| **인증/권한** | 참여자·크루·사장님 3역할 분기. RLS(Row Level Security)로 DB 레벨 접근 제어 |
| **데이터/집계** | 카드 1장 → `/collection` 도감 + `/impact` 진척도 자동 반영 |
| **사장님 답신** | Gemini 편지 초안 → 사장님 직접 다듬기 → 발송 (Human-in-the-loop) |
| **배포/운영** | Vercel CI/CD, PR 단위 미리보기 배포 / Supabase Storage·Auth 매니지드 운영 |

## 10. 정보 구조도 (IA)

접근 권한에 따라 공개 / 참여자 / 크루·관리자 / 사장님 4개 레이어로 구성

```
강화유니버스 (ganghwa-universe.vercel.app)
│
├── [공개] /impact                     임팩트 대시보드
│         ├── Section 01 노드맵        카테고리-프로젝트-가게-참여자 관계 시각화
│         ├── Section 02 카테고리 현황  라이프 / 네트워크 / 창작 / 테크 진척도
│         └── Section 03 최근 카드     오늘 강화도에서 일어난 순간 피드
│
├── [참여자] /entry                    카드 작성 진입 (QR 또는 링크)
│         └── 카카오 로그인
│                  └── 카드 작성      사진 + 메모 입력
│                           └── /collection          내 도감
│                                     ├── 카드 목록   내가 남긴 카드 전체
│                                     └── 카드 상세   앞면(사진+메모) / 뒷면(사장님 편지)
│
├── [크루] /crew                       오늘 들어온 카드 목록
│         ├── 카드 공개/비공개 토글
│         ├── 하이파이브 응답
│         └── /admin                  관리자 콘솔
│                   ├── 카테고리 관리  등록 / 수정 / 삭제
│                   ├── 프로젝트 관리  등록 / 수정 / 삭제
│                   ├── 에피소드 관리  등록 / status 변경 (계획→과정→완성)
│                   └── 가게 관리     가게 추가 / 사장님 코드 발급
│
└── [사장님] /owner                    우리 가게로 들어온 카드 목록
          └── 카드 상세
                    └── 편지 작성     Gemini 초안 → 직접 다듬기 → 발송
                                      (발송 시 참여자 도감 카드 뒷면에 도착)
```

**페이지 간 주요 연결 관계**
- `/entry` 카드 작성 → `/collection` 도감 + `/impact` 진척도 동시 반영
- `/admin` 에피소드 '완성' 마킹 → `/impact` 카테고리 진척도 자동 갱신
- `/owner` 편지 발송 → 참여자 `/collection` 카드 뒷면에 답신 도착
- `/impact` 로그인 없이 접근 가능 → 예비 여행객 유입 경로
